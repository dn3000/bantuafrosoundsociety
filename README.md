# BASS: Bantu Afro Sound Society

A content and discovery platform for South African house music, covering artists, releases, playlists, videos, charts and editorial.

**Live site:** https://bantuafrosoundsociety.com

## Stack

Next.js (App Router) · TypeScript · Tailwind CSS · Supabase (Postgres, Auth, row-level security) · Anthropic Claude API · Vercel

## My role

I designed it in Figma and built it end to end, covering the front end, the Supabase schema and policies, the content tooling and deploy. I also made its motion graphics in React with Remotion, in a separate project. After a performance audit, I brought the homepage down from 3.85MB to 0.38MB and fixed its heading structure.
